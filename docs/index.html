About this PoC

This site checks a PoC that uses out-of-bailiwick ADDITIONAL glue in a DNS delegation response and a certificate forged with a recovered eMudhra intermediate CA private key. DNS and TLS are checked separately.

If a recursive resolver trusts the glue, DNS is steered to a fake nameserver. Even then, the connection fails if the browser rejects the certificate. That intermediate state is shown in the result.

Checks

Each button sends HTTPS requests to a check endpoint. Results are shown on this page.

DNS path

Connects to a random subdomain over HTTPS and shows which nameserver answered.

TLS verification

Connects to a host presenting the forged certificate and checks whether the certificate is accepted. If the connection fails, a control request to a host with a valid certificate helps tell a certificate rejection apart from a network failure.
